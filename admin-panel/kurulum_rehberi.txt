KURULUM REHBERI - Admin Panel Projesi
======================================

ONKOSULLER
----------
Sisteminizde asagidaki yazilimlarin yuklu olmasi gerekmektedir:

1. Docker Desktop (Windows/Mac) veya Docker Engine (Linux)
   Indirme: https://www.docker.com/products/docker-desktop/

2. Docker Compose (Docker Desktop ile birlikte gelir)
   Versiyon: 2.0 veya uzeri

3. Git (projeyi indirmek icin)


ADIM ADIM KURULUM
------------------

Adim 1: Projeyi indirin
   git clone <repository-url>
   cd admin-panel

Adim 2: Docker Desktop'un calistiginden emin olun
   docker --version
   docker-compose --version

Adim 3: Projeyi ayaga kaldirin
   docker-compose up --build

   NOT: Ilk calistirmada Docker image'lari indirilecegi icin 5-10 dakika
   surebilir. Sonraki calistirmalarda cok daha hizli olacaktir.

Adim 4: Servislerin hazir oldugunu kontrol edin
   Asagidaki ciktilari gordugunuzde sistem hazirdir:
   - "admin_panel_backend  | Uygulama baslatiliyor..."
   - "admin_panel_log_service | [LOG SERVICE] Dinleniyor..."
   - "admin_panel_frontend | Local: http://localhost:3000/"

Adim 5: Tarayicidan erisin
   - Frontend: http://localhost:3000
   - API Docs: http://localhost:8000/docs
   - RabbitMQ: http://localhost:15672


GIRIS BILGILERI
---------------
Supervisor (Tam yetkili):
   Kullanici: supervisor
   Sifre: super123

Ogrenci Grubu:
   Kullanici: ogrenci1 / Sifre: ogr123
   Kullanici: ogrenci2 / Sifre: ogr123

Okul Grubu:
   Kullanici: okul1 / Sifre: okul123
   Kullanici: okul2 / Sifre: okul123

Isletme Grubu:
   Kullanici: isletme1 / Sifre: isl123
   Kullanici: isletme2 / Sifre: isl123

RabbitMQ Yonetim Paneli:
   Kullanici: rabbitmq_user
   Sifre: rabbitmq_pass


KULLANIM
--------
1. http://localhost:3000 adresine gidin
2. Login ekraninda ornek hesaplardan birini secin
3. Supervisor ile giris yaparak grup ve ekran yonetimini yapin
4. Farkli gruplarla giris yaparak atanan ekranlari gorun

Supervisor Islemleri:
   - Grup Yonetimi: Yeni grup ekle, mevcut gruplari duzenle/sil
   - Ekran Atama: Gruplara ekran ata, yetkileri (C/R/U/D) ayarla
   - Kullanici Yonetimi: Yeni kullanici ekle, gruba ata

Dosya Yukleme:
   - Dosya Yonetimi ekranindan dosya yukleyin
   - Desteklenen tipler: txt, png, jpg, jpeg, pdf, docx, xlsx
   - Yuklenen dosyalar uzerinde AI analizi calistirin

AI Analiz:
   - Dosya uzerinde "AI Analiz" butonuna tiklayin
   - TXT dosyalarinda PROMPT: veya SORU: ile baslayan satirlar islenir
   - DOCX dosyalari HTML'e donusturulur
   - AI Analiz panelinden direkt prompt gonderin


SORUN GIDERME
--------------
Sorun: Port cakismasi
Cozum: docker-compose.yml dosyasindaki port numaralarini degistirin

Sorun: "Connection refused" hatasi
Cozum: Servislerin hazir olmasini bekleyin (30 sn - 1 dk)

Sorun: Veritabani hatasi
Cozum: docker-compose down -v ile volumeleri silin, tekrar docker-compose up --build yapin

Sorun: Frontend baglanamadi
Cozum: Backend servisinin calistigini kontrol edin: docker logs admin_panel_backend

Loglari gormek icin:
   docker logs admin_panel_backend
   docker logs admin_panel_frontend
   docker logs admin_panel_log_service
   docker logs admin_panel_ai_service


PROJEYI DURDURMAK
-----------------
Normal durdurma:
   docker-compose down

Tum verileri silerek durdurma:
   docker-compose down -v
