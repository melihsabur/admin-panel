PROJE ACIKLAMASI - Cok Gruplu Admin Paneli
==========================================

1. GENEL BAKIS
--------------
Bu proje, farkli kullanici gruplarinin (Ogrenci, Okul, Isletme) yonetilebilecegi,
her gruba farkli ekran ve yetkilerin atanabilecegi bir admin panelidir.

Sistem, mikroservis mimarisinde tasarlanmis olup her bir servis Docker container
olarak calisir. Servisler arasi iletisim RabbitMQ uzerinden RPC pattern ile
saglanir.

2. MIMARI YAPI
--------------
- Frontend: React 18 + Vite + TailwindCSS
  Kullanici arayuzu modern ve responsive tasarlanmistir.
  Login ekranindan sonra kullanicinin grubuna gore dinamik sidebar gorunur.

- Backend API Gateway: FastAPI (Python 3.11)
  Tum API istekleri bu servis uzerinden islenir. JWT tabanli kimlik dogrulama
  kullanilir. Her islem RabbitMQ'ya mesaj gondererek loglama yapar.

- Veritabani: PostgreSQL 15
  Tablolar esnek veri yapisi icin JSONB formatinda veri tutar.
  id (SERIAL), created_at (TIMESTAMP), data (JSONB) seklinde yapilmistir.
  Trigger'lar ile otomatik loglama ve updated_at guncelleme yapilir.
  Function'lar ile yetki kontrolu ve istatistik sorgulari yapilir.
  Procedure'lar ile ekran atama ve kullanici olusturma islemleri yapilir.

- Cache: Redis 7
  Sik erisilen verilerin onbelleklenmesi icin kullanilir.

- Mesaj Kuyrugu: RabbitMQ 3
  Servisler arasi asenkron iletisim icin kullanilir. RPC (Remote Procedure Call)
  pattern'i ile islem sonuclari subscriber'lara bildirilir.
  3 adet consumer servisi vardir: Log, File, AI

3. TEMEL OZELLIKLER
-------------------
a) Cok Gruplu Yetki Sistemi:
   - Supervisor tum gruplari ve ekranlari yonetir
   - Her gruba farkli ekranlar atanabilir
   - CRUD yetkileri (Create, Read, Update, Delete) ekran bazinda ayarlanabilir

b) Dosya Yonetimi:
   - Desteklenen dosya tipleri: txt, png, jpg, jpeg, pdf, docx, xlsx
   - Dosya boyutu limiti: 10MB
   - Grup bazli dosya erisimi

c) AI Analiz:
   - Metin dosyalarinin analizi (kelime sayisi, satir sayisi vb.)
   - TXT dosyalarindaki PROMPT: veya SORU: ile baslayan satirlari isler
   - Word dosyalarini HTML'e donusturur
   - Gorsel dosya bilgi analizi

d) Tam Loglama:
   - Tum CRUD islemleri loglanir
   - Login/Logout islemleri loglanir
   - Dosya islemleri loglanir
   - Filtreleme ve arama destegi

e) RabbitMQ RPC:
   - Her islem sonucu mesaj olarak doner
   - Correlation ID ile islem eslestirme
   - Basari/Hata durumu subscriber'lara bildirilir

4. KULLANILAN TEKNOLOJILER
--------------------------
Frontend: React 18, Vite 5, TailwindCSS 3, React Router 6, Axios, Lucide React
Backend: FastAPI, SQLAlchemy 2, Pydantic 2, python-jose, passlib, aio-pika
Database: PostgreSQL 15, Redis 7
Message Queue: RabbitMQ 3
AI: python-docx, metin isleme
Container: Docker, Docker Compose
Diger: bcrypt, aiofiles, asyncpg

5. VERITABANI YAPISI
--------------------
Tum tablolar ayni temel yapiya sahiptir:
- id: SERIAL PRIMARY KEY (otomatik artan)
- created_at: TIMESTAMP (olusturulma tarihi)
- updated_at: TIMESTAMP (guncellenme tarihi)
- data: JSONB (esnek veri alani)

Tablolar:
- users: Kullanici bilgileri
- groups: Grup bilgileri
- screens: Ekran tanimlari
- group_screens: Grup-ekran iliskileri ve yetkileri
- files: Yuklenen dosya bilgileri
- logs: Sistem log kayitlari

Trigger'lar:
- trg_users_update_timestamp: updated_at otomatik guncelleme
- trg_audit_user_changes: Kullanici degisikliklerini loglama
- trg_audit_group_changes: Grup degisikliklerini loglama
- trg_audit_screen_assignment: Ekran atama degisikliklerini loglama

Function'lar:
- fn_get_group_screens(): Grubun ekranlarini getirir
- fn_check_permission(): Yetki kontrolu yapar
- fn_get_stats(): Genel istatistikleri dondurur

Procedure'lar:
- sp_assign_screen(): Ekran atama
- sp_remove_screen(): Ekran kaldirma
- sp_create_user(): Kullanici olusturma (validasyonlu)
- sp_bulk_assign_screens(): Toplu ekran atama
